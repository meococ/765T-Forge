# Demo metro standards pack

Synthetic **reference** pack for CI/docs/demos. It is **not** a Vietnamese national CAD standard.

Copy and edit for each real project from the consultant CAD Manual / BEP.

Load in AutoCAD session:

```text
forge_pack_load path=<repo>/packs/demo-metro/standards.pack.json
forge_registry_load path=<repo>/evals/fixtures/drawing-registry.json
```
